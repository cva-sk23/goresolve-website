True Balance Loan Review (2026) – Harassment, RBI Rules, Settlement & Real Borrower Experience

What is True Balance Loan?

True Balance is a digital loan app offering:

  • Personal loans
  • Instant loans
  • Short-term loans
  • EMI repayment loans

Many borrowers use True Balance for:

  • Emergency expenses
  • Medical bills
  • Salary gaps
  • Small personal needs

However, borrowers also report collection pressure and recovery calls after missed payments.

True Balance Harassment Complaints

Borrowers often report:

Frequent Calls

Many users report:

  • Multiple calls daily
  • Calls from different numbers
  • Continuous reminders

WhatsApp Messages

Some borrowers report:

  • Repeated WhatsApp reminders
  • Payment pressure messages
  • Settlement offers

Contacting References

In some cases:

  • Friends contacted
  • Family contacted
  • Work contacts contacted

This is where harassment concerns begin.

Is True Balance Harassment Legal?

No.

If recovery agents:

  • Threaten
  • Abuse
  • Call outside allowed time
  • Contact relatives repeatedly

This may violate RBI guidelines.

RBI Rules for Recovery Agents

Recovery agents cannot:

❌ Call before 8 AM
❌ Call after 7 PM
❌ Threaten borrower
❌ Contact references repeatedly
❌ Use abusive language
❌ Public shaming

If this happens → You can complain.

True Balance Recovery Calls – What is Normal?

Normal recovery:

  • Reminder calls
  • Payment requests
  • Settlement offers

Harassment:

  • Threatening language
  • 20+ calls daily
  • Calling relatives repeatedly
  • Abusive tone

Know the difference.

What Happens If You Don't Pay True Balance Loan?

Here is what usually happens:

  1. Payment reminder
  2. Recovery calls
  3. Settlement offer
  4. Legal notice (rare early stage)
  5. Civil recovery case (rare)

Important:

⚠️ No police arrest
⚠️ No criminal case
⚠️ Loan default is civil matter

True Balance Settlement

Yes — settlement is possible.

Settlement depends on:

  • Loan amount
  • Overdue period
  • Financial hardship
  • Negotiation

Many borrowers:

  • Accept first offer
  • Panic pay
  • Overpay

Better approach:

  • Negotiate calmly
  • Ask for written settlement
  • Verify closure letter

How to Stop True Balance Harassment

Follow these steps:

Step 1 — Request Email Communication

Tell them:

"Please communicate only via email"

Step 2 — Record Calls

Keep evidence

Step 3 — Send Warning Email

Mention RBI guidelines

Step 4 — File Complaint

You can complain to:

  • True Balance customer care
  • RBI complaint portal
  • Banking ombudsman
